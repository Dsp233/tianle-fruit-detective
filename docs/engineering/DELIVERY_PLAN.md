## 4. 唯一可执行队列与后续接力

1. 核查最终 RC 已测运行源码/工件/哈希和可复用 G1–G4、FIX15 回退专项证据，仅补**确有缺口**的非真机必要检查，不重复规划或审校。
2. 独立浏览器验收：有合法可访问测试环境则 Muse 实际操作并留证；访问不足则维持 BLOCKED_ACCESS，记录证据范围及发布风险决定，严禁冒充 PASS。
3. **核对适用于本次发布的明确授权**后，以冻结同字节运行文件执行 G5，公网核验首页、阅读和数学主入口、版本/哈希、历史数据保护及回退。G5 不成功不报 W1 上线。
4. W1 G5 实际完成之后转入 **G0-B 代码治理** → M → W2 → 产品体验收口 → 全系统集成 → **最后统一 UAT**。G0-A 只读审计可现在并行。
5. GitHub 写入前核对 HEAD + expected SHA；HEAD 改变先比较并整合，真实冲突仅暂停相关写入。本次方案优化限文档，部署由后续具有相应授权的执行任务开展。

W1 完成 G5 公网核验后标 `RELEASED_PENDING_DEVICE_UAT`；缺真机不再计工程 BLOCKED，但不可称 `FULL_UAT_PASS`。剩余若仅授权/托管受限，具体记录阻断，其他可执行工程工作继续。
