- **Work 的任务是关闭门禁和交付产物**，不是增加提交数。每轮结果必须报告：已关闭门禁数/未关闭 P0-P1 数、唯一候选 SHA、CI ID、包 SHA、预览 URL（或唯一托管阻断）、实际 iPad 版本及下一项明确工作；不输出没有实质变化的进度长文。
- **新增或补充验证的准入四要素**：原始合同条款、**已有证据缺口或可复现缺陷**、最小验证范围、客观关闭标准。既有必要功能缺证据时直接补验证，不要求先发现错误；发现实际错误后再列最小修复。数据改动只补关联拼音/内容；存储变更才重跑受影响故障矩阵；运行文件必修变更合批后完成适用完整候选 PASS；**纯文档变更不重跑 CI**。
- **并发**：用户已授权单一 Work 会话作为 W1 写入者；每次检查 HEAD + expected SHA，不强推，不以无法查看其他 Work 会话为永久只读阻断，遇具体冲突才合并/暂停相应文件。
- **连续执行**：收到用户新的“继续 W1”时，Work 在本次可运行会话内完成下一项可执行工作；保存断点、等待某个 CI 完成、单次局部成功、外部 iPad 缺失都不构成停止**其余可执行任务**的理由。不承诺聊天结束后仍在后台运行，也不将额度重置理解为自动恢复。

- **发布禁令**：未关闭发布 P0/P1、原合同 G1–G4-E 未通过、冻结包与预览设备版本不一致，均**不得触碰 main、部署或宣称验收完成**。T 的长期儿童学习效果单列，不得既用它强行放行内容缺陷，也不得用它无限拖延已完成 E。
