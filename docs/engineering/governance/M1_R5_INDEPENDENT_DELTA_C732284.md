以两份实际冻结入口在各自空状态的 Node VM 中执行原有题页渲染器 `jointPage()`，抓取 `nativePrompt`、`jointMaterialText`、`jointFields`、首屏完整题页 HTML 及无提交时打开提示的 HTML。直接渲染时临时允许进入目标角色，以取得平时受进度限制的题面。对同一轮的两个候选固定相同选项排序种子，换种子重复一次，两轮结果一致。知识页通过原有 `playerPage()` 输出。核对包括题页上的主目标、支持知识、材料与角色设置等可见信息，可作为七维历史审核的内容差异证据。

Chromium 在此执行环境启动即报 `socket() failed: Operation not permitted (1)`。这里验证的是原渲染器生成的题面和标签，未进行正常路径解锁、作答提交、判分、反馈与记录、真实隔日访问、语音、CSS 实际绘制或儿童使用观察。独立计算只依据可见材料。未读取判分函数或开发者答案，也未写队列或对新候选签收题族。

## 13 项对照独立推导

新增部分在全部 13 道题里标明与订单分别作答。两道计算输入对应下表左右两量，保留原题操作及原订单。新增比较均通过材料文字、文字图标或坐标给出，没有新增第二套可操作图形。

| 变动实例 | 可见条件、独立计算与反例判断 |
|---|---|
| `J-A05-06-C` | 从 1 件逐轮乘 3，得 3、9、27，直接加三个 3 得 9。**27 对 9**，三轮乘法与三个相同数相加不同。原操作仍为一轮，三轮由单独的对照文字和输入承担。 |
| `J-G02-02-C` | 甲从正上方顺时针到正下方走半圆。乙经过正下方一次再回正上方走整圆。**180° 对 360°**，起止信息和中途条件区分两条扫过路径。原订单操作仍为 60° 与 30°。 |
| `J-G03-01-C` | 两份用 AAA/BBB 和 ABB/ABB 标出的铺法均覆盖同一块 2×3 格目标板，每格 1 平方厘米。选一份采购 **6 平方厘米**，重复算两份得 **12 平方厘米**。拼法改变而目标总面积不变。 |
| `J-G04-03-C` | 半径 6 厘米，甲乙共走同一半圆弧 (6\pi) 厘米。两项输入问的是额外直线长度，故填 **0 厘米对 12 厘米**。两条全程分别为 (6\pi) 和 (6\pi+12)，直径只属于闭合边界。原订单仍用原生弧段。 |
| `J-G05-02-C` | 原长宽比为 4/2=2。甲仅横向放大到 6/2=**3**，乙横纵都放大到 6/3=**2**。单轴拉伸改变长宽比，双轴同倍缩放保留长宽比。 |
| `J-D01-01-C` | 每枚完整圆标代表 4 件，半枚代表 2 件。甲行 ●◐ 得 **6 件**，乙行 ●● 得 **8 件**。按图标个数直接读会把两行误当成相同。 |
| `J-D01-03-C` | 物品在底格上方两格，每格增量 5。正确起点给 10+2×5=**20**，误用零起点给 0+2×5=**10**。同一相对位置在不同起点的读数不同。 |
| `J-D01-05-C` | 原图乙类 3 枚，每枚 2 件，原数据为 6 件。相同三格柱高按图 A 读 3×2=**6 件**，按图 B 读 3×1=**3 件**。只有 A 保留原数据，外观相同不能确定换算正确。 |
| `J-D01-06-C` | 点间为直线。上坡和下坡分别在第 1、5 分钟穿过阈值 2。达标区间为 1 至 5 分钟，共 **4 分钟**。四个原始记录点只有第 2、4 分钟两个值达标，即 **2 点**。累计时长与达标点数不同。 |

13 个对照的两个响应都能从可见条件唯一算出，且每组结果可区分。审阅中需要辨清的口径是半圆题填写直线增量，旋转题填写终点横坐标，最小值题填写数值而非卡名。前三项分别在字段中明示。对照题用文字呈现的形式依赖阅读，实体操作的教学体验仍是本次证据的边界。
