# 功夫学堂首页 H1

首页为「阅读训练」「数学侦探」两个独立入口；数学知识筛选、判分与去重规则保持原有约束。不能开始时明确显示缺少的知识声明、题号筛选、负担限制或没有合格新题。不会自动勾选知识或静默扩大来源；若有范围内的原创题，只提供显式开启按钮。

配图使用内置图片生成工具。最终图片已嵌入 `overlay/source/home_portal.js`，项目内还保留优化后的 `assets/home-panda.webp`。提示词：原创幼年大熊猫，穿翡翠绿练功背心，在竹林庭院里读绘本、观察木制几何积木；温暖自然光，奶油白、竹绿和金色，无文字、无标志。图片是原创角色。

验证包括69项CPU门禁、9项首页/选题/记录兼容专项、完整阅读自动回归，以及真实浏览器的两个入口、无效/有效混选、实际作答、往返与刷新后的记录、320/768/1180宽度布局。此前N2的完整82项验收保留为历史记录，不冒充H1的新验收。人类教学、可听语音、实体设备与真实儿童效果仍待观察。

`refresh_context.js` 先比较95族、380项原任务和380份判分合同，结构数据必须完全相同，才能更新来源上下文；旧审核范围、逐实例评语、目标和结论均保持原样。
