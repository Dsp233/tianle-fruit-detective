# RC79 LOAD1：全站加载专项修复

基线为已经上线的 `63c9a525bc613dbee3a5afb52043963b146ce473`，仅修改内容交付和模块启动方式。依据用户要求，不执行完整版本验收。

- 首页保留原有两个入口，HTML 直接包含可见首页，不等待题库初始化。
- 阅读引擎、内容、拼音及媒体按阅读入口加载，不下载数学数据。
- 数学按数学入口加载；题库对象作为压缩数据包解析，避免大体积 JavaScript 对象字面量的编译负担。原始 JSON 作为不支持原生解压浏览器的兼容路径。
- 原题 PNG 按 SHA-256 分离为静态图片，像素与字节保持一致，只在题目展示时请求。
- 公共 HTML 的 CSS/JS 改为可复用、按内容哈希命名的资源；学院、QA、旧版预览和维护入口保留原路由与各自存储键。
- 加载进度、超时和明确的重试按钮替代无反馈白屏；不清理浏览器数据，不升级存储或证据规则。

`package.py` 是在原有完整 HTML 构建之后执行的发布步骤，不修改题目、判分或审核结论；再次执行前必须先构建/恢复原始输入。`loader.js` 通过可重绑定的阅读宿主，在数学尚未启动时独立展示阅读，并在数学启动后继续使用同一份阅读引擎与草稿。

专项验证仅包括：所有处理页面资源路径、生成脚本语法、Chrome/WebKit 首页及两模块加载、草稿与选择跨模块/刷新保留、无原生解压兼容路径、失败重试和 8 个活动入口。公网发布后使用相同范围的加载专项复核。WebKit 自动化不能替代真实 iPad 验收，真实设备状态保持未测试。
