# 星空观察簿阅读试玩候选

这是与正式课程隔离的家长陪同审校试玩页：七天连续故事，分短格展示；每天三道核心任务及一道可选挑战。第 4、5、6 天提供可操作的路线、真假线索、装袋探索。用户可切换逐字拼音、尝试系统本地普通话朗读和点字听读。

页内所有作答只存在内存，不读取或写入现有数学和阅读记录；刷新或关闭将丢失试玩过程。家长可主动下载本次试玩记录，文件不会发送到服务器。此记录不计正式课程或独立掌握证据。

拼音由固定版本 pypinyin 编译并进行覆盖与对齐检查，未完成独立中文审校；模拟音频回调不代表实际音色、播放完成或听清。故事难度、互动趣味、漫画一致性、真实 iPad 与天乐的实际反应均待检查。正式课程接入前仍需兼容旧记录、设计课程迁移并完成所需审校。
