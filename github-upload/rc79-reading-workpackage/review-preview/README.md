# W1 独立预览站评审批注工具（非正式学习程序变更）

## 功能范围

- `review.html` 为完整自包含 HTML（CSS/JS 内嵌）。在同一独立 HTTPS 预览站的站点根目录放置此文件，与原冻结 `index.html` 同级；评审访问 `/review.html`，原学习程序仍走 `/`。
- iframe 加载相对地址 `./index.html`：评审时顶层 capture 事件阻止跳转、答题等用户点击；退出评审模式后原应用正常工作。**必须与学习程序同源**，否则浏览器阻止精确元素定位。
- 评审模式：hover 高亮或触摸点选，自动记录路径、页面标题、CSS selector、元素文本、所在卡片、相对位置；五类意见与可选提出人；保存后显示红色编号，点编号可编辑；清单可修改、处理、删除、隐藏标注。
- 可编辑版本号和日期，一键复制 Markdown 或下载以版本日期命名的 `.md`。导出所有意见，包括处理状态和复现坐标。
- 所有记录仅保存在本浏览器同域的**专用** localStorage 键 `tianle_w1_device_review_v1`，不操作学习进度记录。清缓存、换域、换设备不会自动同步，必须导出 Markdown。
- RC 源码身份：`c8575da9d28c40b5bf79412928a0be8c397e7094`，原通过 CI `42425597193`，原发布 ZIP Artifact `13595790278`。评审 UI 不属于原冻结运行字节，保持旧包中 437 个网站运行文件逐文件 SHA 不变。

## 安全交付

1. 只给现有独立预览域名添加新文件 `review.html`（站点根目录），不变更原 `index.html` 及学习资源；正式 FIX15 保持不动。
2. 若托管系统要求整站重传，必须使用来自成功 CI 的同源已测运行文件打包，加上新增评审入口；校验 437 个文件 SHA。不可重新编译冻结 RC 并沿用旧验收。
3. 检查 `/review.html` 可公开访问，手机框正常加载冻结 W1 应用；评审开启时原按钮点击被拦截，退出后恢复；标注、隐藏、版本/日期、复制与下载在真实设备核对。
4. 评审工具体验验收与 W1 G4-E 的实体 iPad 内容/声音/保存验收分别记录；不能将评审工具测试冒充 G4-E PASS。
