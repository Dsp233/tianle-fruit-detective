评审流程 01 / 04

边体验，边批注。

开启评审后，移动鼠标或触摸屏幕，系统自动识别被点选的元素和所属卡片。

  1. 开启评审模式，点击需要修改的地方。
  2. 选择分类，写下修改意见并保存。
  3. 退出评审模式，正常翻页或做题，回来标注仍在。
  4. 打开评审清单，隐藏标注以便截图，复制或下载 Markdown。
数据保护所有批注只保存在当前浏览器的独立评审存储，不上传服务器，不读取或修改学习进度。跨设备请通过导出的 Markdown 传递。
