# 新课程字音表筛查记录

- 范围：新课程84天的标题、正文各段、336题的题干、选项、提示、解释及字符串条目，按完整字符串去重；不重复核算共用正文。合并正文与分段注音相等由 `test_reviewed_pinyin.py` 另行断言。历史课程、动态辅助板及界面文字不在本次范围。
- 用 `wp-course-data/screen_character_readings.py` 对照 [python-pinyin 单字读音表](https://github.com/mozillazg/python-pinyin/blob/88a0102e986886fa623e923c61d6705ffac4baa6/pypinyin/pinyin_dict.json)；字典是外部审校辅助，不进入产品依赖。输入去除末尾换行后的 SHA-256 `5f294c01e6c6c0a1c8e329c79335a3f8e0b27d06bf1de7a99244b765892d1e5b`。
- 对内容哈希 `71e53b7035d8a7a415473ffe204e95095ec9cb1b7004d75f9c41bb59dd418325`、注音表哈希 `b4136fc3f439b6df38bfa182cdd02195601ed0632efdce5e9afa3826703f6847` 的数据，2,283 个不同字符串、38,249 个汉字位置全部存在等长注音。单字表标记44处；逐条按其所在词复核，均为字典不列出的轻声：这个/哪个的 `ge` 27处、告诉 `su` 6处、多少 `shao` 6处，意思 `si`、清楚 `chu`、答应 `ying`、便宜 `yi`、结实 `shi` 各1处。
- 单字表只能判断读音是否属于该字的候选音，无法判断多音字在具体句子中的选音、教学语言、拼音渲染、语音听感或儿童理解；本筛查不是G1整体通过，也不替代已记录的定向语境审校或实际听音。
