# G2 草稿合同与当前恢复边界

## 已有合同

`docs/engineering/DELIVERY_PLAN.md` 要求保留历史数学／阅读原文、首答、草稿、求助及旧档案，提供恢复与导出；G2要求配额或冲突时保守处理、匹配旧软件和旧原文回退、升级后原文另存。文档未明确规定未提交的纯内存草稿必须自动写回旧界面，但“保留”和“恢复可用”不能被改写为仅有一个无法识别或无法操作的文件即通过。FIX7历史登记还要求已支持数学会话的草稿恢复；FIX15收据明确把异步保存前关闭可能丢失未保存草稿列为未关闭项。

## 已验证范围与操作

1. 在原候选页停止作答，等待保存状态稳定，导出完整学习记录，确认下载文件实际存在；保持原浏览器数据，并关闭其他学习页。
2. 使用测试过的 FIX15 恢复页面在原环境生成档案。数据不一致、无法读取或发生竞争时应保留导出及源数据，不能强制覆盖。
3. 在同一软件来源的全新隔离浏览器环境中，关闭其他学习页，导入档案并等待逐键校验通过。失败或部分写入时保留档案，改用另一个全新隔离环境重试。
4. 查看档案中的任务草稿／待保存答题并下载原始完整导出；对匹配的题目、版本和数据逐项人工核对。未保存草稿不会自动写回FIX15；未保存记录不能冒充首答或通过。

CI `41398678479`、`41402586558`、`41403349884` 和 `41404695712` 覆盖合成记录的固定软件恢复、原文比对、浏览器页面下载与草稿归档查看；不能从中推导每一种未提交题型都可人工重建。CI `41489441417` 证明事务被阻塞时关闭页面保留已提交旧值，也明确未导出的内存内容无法从磁盘恢复。CI `42382618286` 在 Chromium/WebKit 使用真实 FIX15 页面生成合成数学会话，保存未提交输入，经隔离回退后核对相同 attemptId 和输入并继续该会话；只证明此类已持久化会话。真实 iPad 和实际用户数据未测试。
