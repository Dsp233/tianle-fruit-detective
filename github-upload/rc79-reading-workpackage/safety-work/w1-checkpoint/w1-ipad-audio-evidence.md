# W1 实体 iPad 与实际听音证据

状态：**BLOCKED / NOT_RUN**。本记录是可执行的验收步骤，不是设备测试结果。仅对实际测试的候选包和设备有效；自动化 WebKit、触控模拟或语音 API 被调用均不能代替此证据。

## 准备

1. 使用最终通过集成 CI 的同一个候选工件，在与正式站不同的隔离测试地址提供完整静态文件；校验工件 SHA-256 及 `tested-package-inventory.json` 中的文件哈希。测试地址应使用 iPad Safari 可用的安全上下文，并确保浏览器存储可用。不要在正式站的真实用户记录上做实验，也不要为测试清除原浏览器数据。若无法提供隔离测试地址或确认文件一致，设备验收继续 BLOCKED。
2. 记录候选源码 SHA、下载工件 SHA-256、测试地址所对应的文件校验结果、iPad 型号、iPadOS/Safari 版本、日期，以及扬声器或耳机。使用新建的合成练习数据，不记录孩子姓名或真实答题信息。

## 操作与预期

| 操作 | 预期结果 |
|---|---|
| 用实体 iPad Safari 打开候选首页，从数学入口进入一题，点选一个答案后尝试离开，并在提示中取消 | 当前题目与所选内容保留；出现可用于导出的记录/草稿入口。若直接无提示丢失则记 FAIL。 |
| 完成一题数学练习并刷新，再查看记录 | 保存状态正常，已提交记录仍在；如有保存失败提示，保留导出并记 FAIL。 |
| 进入阅读地图第1天，阅读后对一题先选错并提交，再改正确；刷新并继续 | 操作可触达，刷新后可续做，原错误首答仍保留，后续正确回答不覆盖首答。 |
| 从当天结束页进入自愿挑战；查看家长端或记录 | 挑战可进入；已见原文被标为已见，不额外算成完成一天。 |
| 第15天第1题尝试排序点击和拖动；第64天第1题操作纸条；第68天第1题操作对称方格 | 触控、滚动、按钮状态可用；排序已选项的拼音仍与原选项一致，纸条和方格操作不意外提交。 |
| 在阅读中切换拼音，分别触发全文、单格、题干和选项朗读；实际用耳朵听 | 拼音可见/隐藏；实际听到可理解的中文声音，停止和重试有效。如无声音、错误读音或明显卡住，记 FAIL 并保留复现步骤。 |
| 打开家长端的历史诊断入口 | 13套旧诊断入口保留且标明旧版，旧诊断不混入新课统计；不要以此结果推定教学效果。 |

## 证据与判定

逐项记录 PASS / FAIL / BLOCKED、操作时间和简短观察；至少保存显示候选版本、触控与保存结果的截图，以及能证明实际听到朗读的人工记录或设备录屏。音频、截图中不要包含真实学习记录。任何关键操作失败、无法验证候选包一致性或无法实际听到声音时，G4-E 不通过；设备测试通过也不能替代 G1、G2、G3 或发布后的 G5。
