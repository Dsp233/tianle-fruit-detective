# 动态辅助板注音修订

- 审看已集成辅助板文字时发现，数字或状态拼接会使完整字符串不同于精确注音表的键；界面因此退回单字读音，即使原文本已有精确注音也可能误读。
- 排序选项的数字编号只作显示标记：在选项全文没有独立精确项时，复用编号后原选项的精确注音；完整字符串本身的精确项仍优先。
- 对实际辅助板中出现的“题目要求”“只能对应”“先后要求”和标点后的“：要求”，仅在完整文本没有精确项时使用带上下文的限定读音。未改旧课程注音表或全局“要、应”单字读音，避免将跨词的“需要/求证”等误当“要求”。
- 从辅助板源码直接提取152条去重的 `rt` 与按钮静态单引号文本，检查其中79条含选定常见多音字的注音及语境；修正“保留为未知”的 `wéi` 与“两条都重来”的 `chóng`。两条标签原已在新资料精确表中，修改前确认旧课程精确表没有同名条目。
- `wp-ui/test_order_pinyin.js` 使用和旧单字回退不同的注音验证选项编号、限定语境、精确表优先及一般回退不变；最终构建工作流包含该测试。生成 UI SHA-256 `85661764c8f22e3fafc9bc3c7cc3e01424dcabb3e3f1836be764712e18a17da6`。
- 辅助板其余动态拼接、语境和实际听音仍需审查；本记录不作为完整 UI 拼音或设备验收。
