# 诊断材料草案（未启用）

这里是后续诊断工作包的隔离草案，**不是可用诊断**。当前正式课程数据只保留旧版 13 套诊断；新版课程作用域不会把它们当成新版诊断。当前引擎会拒绝启动此处所有未审校套题。不得把本目录输出直接并入生产数据或发布。

`reading_cases.py` 包含 14 组、每组 4 篇原创阅读草案；前 13 组作为基线及第 1—12 周的初步草案，最后 1 组完整保留作未分配备用。`math_cases.py` 和 `build_diagnostics.py` 生成配套的 13 组×4 篇数学读题草案；每份表单由阅读材料和数学读题材料各 1 篇、每篇 2 题组成。标题、情境和数量经本轮编辑，但数学题仍有同一套题内模板相似的问题，需逐题独立改稿和审校。

`diagnostic_draft.json` 仅包含 13 套新草案，不覆盖或更改旧题。新套题、材料和题目使用新的 `R2-DRAFT-…` 标识；能力、错因及正式先修均为空并标记 `unreviewed`。`proposedDesignSlot`、`proposedPrerequisites` 和旧蓝图副本只是待审设计线索，不可作为孩子能力、先修知识确认或已建立等值的依据。新表单没有预分配 A/B/C/D；现有引擎在真正允许诊断时才按套题和周次轮换条件。草案中保留一个未分配阅读组，防止静默丢失原有工作。

## 复现

在工作区根目录执行：

```bash
python3 safety-work/wp-diagnostics/build_diagnostics.py
python3 safety-work/wp-diagnostics/test_diagnostics.py
node safety-work/wp-diagnostics/test_disabled_engine.js
```

生成器核对旧 `reading_data.js` 的 FIX15 SHA-256，并逐项比较候选中的 13 套旧诊断与旧材料、旧题。结构测试覆盖 13 套、52 表单、104 篇、208 题，验证新旧标识隔离、选项位置分布、字面正文不与现有课程重复、52 个数学表达式与独立算术计算相符，以及输出可重复生成。字面不重复不证明语义不同或测量等值。

Node 引擎测试使用合成记录，将草案临时追加到隔离数据中：验证 13 套未审题全部不能启动、不会产生新条件分配，并且旧首答和升级前精确原始记录仍保留，旧条件不混入当前课程结果。测试不接触真实学生记录。其旧诊断练习入口设计见 `LEGACY-PRACTICE-DESIGN.md`。

还缺独立数学解题、语言自然度、题意和干扰项质量审校；四份材料是否测量相同能力及难度相近需要专业审查和儿童样本验证，不能由题目结构或自动检查证明。新文本尚无逐字拼音、实际朗读、页面/浏览器、实体设备或儿童体验验收。现有教学材料分镜为通用占位。完成这些工作前，保持套题禁用。
