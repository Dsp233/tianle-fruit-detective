## 本轮新增

九类图元均可保存题中量、作用、单位；四个综合主任务具有自动关系核验。输入量名和关系由学生填写，不预填解法。已知量核对题给值；输出量与有向输入相连；同一个数字、无语义箭头及纯计算不等于建模通过。按数量表示时核对实际图形个数乘每个表示量；数量卡、时间标记与表格保留为示意。

上游量或关系改变时沿数据与推理前提使下游失效，不删除独立分支；撤销/重做、刷新保留原图。保存的 verified 标签不能直接认证，恢复后由当前合同重核。图和文字关系可混合构建；完整过程还要求工具、候选的达标/最低费用判断、最终答案都满足合同。

## 新增重点复验

1. 在四个综合主任务中用草图构建关系；默认不出现量或关系的正确选择。
2. 同数不同量、错误单位/作用、跨主变范围、重复量绑定必须保留草稿并解释未核验。
3. 将总人数表示为3个图形、每个10人可核对30人；改成2个必须未核验。
4. 图中上游值修改后，下游需重核；无关分支保留；撤销与重做恢复相应状态。
5. 入队材料固定例可仅用图关系、工具与候选表形成完整过程记录；并列检查数字答对但过程不足的情况。
6. 同一答案下补充新的过程可重新提交；直接双击不能重复记一次提交。
7. 在实际 iPad 检查新增选择框、关系输入、Enter、触屏、窄屏、中文朗读及存储限制。浏览器语音自测仅记录请求，不替代真实发声。
