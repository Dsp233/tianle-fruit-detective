## 修复一：过期候选核验

原复现：入队材料 seed1，核对完整候选表后改为 `0:是`，再次核对提示遗漏，提交324却仍记录策略独立。现在编辑立即撤销旧核验，所有失败分支清空证明；最终提交还重算候选并绑定题目、作业、范围和当前输入。答案正确仍如实记录；过程不足不记独立建模。重新补全并核验可在同一答案下再次提交，重复点击不重复计数。

候选证明合同从2升为3，过程记录版本为2，两者独立编号。旧证明保留但须重新核对。历史综合任务缺少当前过程证据的 verified/策略独立结论保留原值于 legacyProcessEvidence，派生为待复核；首次答对、答案、时间不删除。未知历史过程不参与难度升降。

## 修复二：未知草图格式保护

未知 schema 或题目身份不匹配时保留完整原始 JSON，显示只读提示，禁止编辑、撤销及计算等写操作；提供单份草图与完整记录导出。主题和变式分别保留，保存与刷新不丢未知字段。遇到可支持的原题身份可重新读取；不支持的内容不计建模通过。已被旧版本清空、且没有备份的原文无法凭空恢复。

## 重点复验

1. 完整核验后编辑候选，确认旧“已核验”提示立即消失；失败检查、刷新与提交均不能复用旧证明。
2. 同样的324仍显示数学正确，过程为 insufficient；补全重新核验后可补记 verified，双击不增记录。
3. 恢复 RC71 的旧候选证明及历史策略独立记录，确认原记录保留、显示待复核，且不影响难度升降。
4. 准备 schemaVersion3、999及题目身份不匹配的主/变草图，确认原字段、节点及未知扩展仍可导出；草图编辑输入和变更操作被阻止。
5. 导出单图与完整记录，逐字段对照原文；刷新、切换范围和继续答题后再次核对。
6. 继续 RC71 的40项草图语义回归：上游失效、独立分支、撤销/重做、图文混合、纯草图过程、非预填解法。
7. 实际 iPad 核对触屏、下载、窄屏和中文发声。开发浏览器只验证朗读请求，不证明真实发声。
