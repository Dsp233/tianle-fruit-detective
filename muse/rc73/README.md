## 本轮行为

1. 已答对的原题从自动选题硬排除，含提示后正确、订正正确、主任务及变式的已完成身份。历史明细截断后仍保留排除；新题不足时缩短练习，不重复已解原题。历史手动回看和 QA 定位保留。提示后正确不等于独立掌握。
2. 辅助图首屏隐藏，点击提示才出现；必要条件由完整文字提供。提示位于题目下方、答案上方，并继续朗读；纯数字选项不朗读。
3. 修复 restrictedTeam 提示提前暴露余数、offsetBells 提示预填完整时间轴、repeatedOnes 省略序列末项、recurrence 序号角色、percentRestore 单位与整体基准。包装与散售图分别计数，压缩图明确倍率。
4. 维护页读取七个登记命名空间，分别导出原始字符串、备份、字节数、哈希和局部错误；不合并、不写回进度。未知、损坏格式的原文保留。原页面导出仍遵守本页面 STORE 范围。
5. QA 提供五种草图保护 fixture 的可见准备控件。题目、变式身份及只读保护继续有效；正式练习记录不用于开发测试。
6. 调度按 cgroup 剩余内存和不同任务预算准入。资源不足可零任务等待；有证据的 INFRA 至少 30/120/300 秒后重试，保留每次 attempt；未知崩溃不归为 INFRA。
