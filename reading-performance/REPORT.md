# 阅读训练入口性能

基线为 `f1a3880d9b23b1675a945d759f022d19f1e963ee`，验证提交为 `7fb3ccbbcc0befe4ff25b31730147ba4b61e1867`。修复保留在独立分支，正式站继续使用原版本。

## 同条件实测

GitHub Actions 使用 Chromium 143.0.7499.4 和本地 HTTP gzip 静态服务。每组 7 次，轮换运行顺序。首页资源稳定后注入 180 ms 延迟、160 KiB/s 带宽及 3 倍 CPU 降速。冷启动使用新浏览器上下文并禁用 HTTP 缓存。热启动点击站点标志返回首页，再在同一页面打开阅读。

从真实点击事件计到阅读首页的 `rdStart` 按钮可用。首图完成解码单独计时。入口请求计入按钮可用前下载的资源，传输量采用浏览器 Resource Timing 的 `transferSize`，含响应头。HTTP 层解压由浏览器完成，表中解压耗时只计应用调用的 pako。页面渲染耗时包含引擎初始化子阶段。

| 指标（7 次中位数） | main | 仅并行 | 候选 |
|---|---:|---:|---:|
| 首次进入可开始阅读 | 4.566 s | 4.141 s | 2.973 s |
| 同页再次进入 | 0.042 s | 0.038 s | 0.036 s |
| 首图完成解码 | 6.167 s | 5.742 s | 4.617 s |

| 进入动作及首屏渲染 | 122.1 ms | 120.9 ms | 121.2 ms |

两版热启动均为 0 个入口资源请求。首轮冷启动为 4.484 s → 2.929 s，复测为 4.566 s → 2.973 s。两轮证据分别见 [首轮原始数据](evidence/benchmark-b861c20.json) 和 [复测原始数据](evidence/benchmark-7fb3ccb.json)。

## 加载路径

原版并发上限为 3，先完成 6 个课程数据分片的下载、拼接、解压和解析，再请求 2 个脚本分片。只调整调度时，数据量相同，首次可开始阅读从 4.566 s 降到 4.141 s。

候选用原生脚本加载和 HTTP gzip，与无损词条引用及拼音差异编码配合。候选仍一次请求整份课程数据，以沿用引擎对当前及历史会话、题目和草稿的完整校验。最后一个课程资源完成仍占主要时间。

## 定向回归

- Chromium 143.0.7499.4 和 WebKit 26.0 均通过。浏览器实际还原的数据与基线逐项相同，覆盖 84 天课程、420 份课程材料、1,829 条拼音和 296 条语境标注。阅读运行脚本逐字节相同，既有图片和内容指纹保持原值。
- 双引擎均通过弱网阅读、图片解码、拼音、合成语音接口、答题、第 84 天选做课和同页重入。弱网测试以服务器 180 ms 延迟与 160 KiB/s 共用链路注入。
- 既有会话的历史完成天数、11 条原有事件、首答和草稿均保留，继续作答与刷新通过。模拟课程数据请求失败后，失败期间原始存档保持逐字节一致，重试成功。损坏记录进入只读并可原样导出。
