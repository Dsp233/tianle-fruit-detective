## 判定标准

| 项目 | 判定 |
| --- | --- |
| ART-01 图文结构 | 每份材料 3 格，正文完整，入口绑定实际数据、资源及裁切。 |
| ART-02 情节差异 | 画面对应每格情节及不同叙事动作，检查跨格及跨日连续性。 |
| ART-03 事实准确 | 对照人物、地点、时间、编号、数量、空间关系与道具状态，画面中可辨认的线索须与正文一致。 |
| ART-04 角色表现与清晰度 | 人物和必要动作可辨认，重要道具、数字与边缘信息在实际裁切内清楚。轻微风格瑕疵原样保留。 |
| ART-05 学堂主题 | 原创熊猫功夫学堂的世界观和角色连贯，主题元素服务阅读。 |
| ART-06 推理完整 | 检查插画、正文、选项、提示及解释的显示顺序，已给线索可以呈现，页内提前显示未得结论、可直接数出隐藏答案或误导性额外线索需修复。 |
| ART-07 浏览器与移动呈现 | 在隔离 Chromium、WebKit 实际浏览器中核对图文及触控布局。有设备时单列实机结果，实体设备、儿童体验、真实语音听感和独立人工审核沿用原方案延期状态，除非实际完成。 |
| 中文自然度及叙事 | 对话像真实人物，词义、指代、因果、先后与段落自然，必要名词可由上下文识别。 |
| 拼音与断词 | 对照实际词边界、上下文多音字、数字/字母/标点混排、长词与句末，验证全拼音、重点、按需和无拼音。固定回归“分别”“登记册”，以及旧问题相关文本。 |
| 阅读负担 | 一年级儿童能凭已提供信息理解人物、物件和任务目标，降低无关识读负担，保留原有思考难度。 |
| 数学题意 | 逐题先依公开材料独立求解，再对照选项、提示、答案和解释；检查约束、单位、不同解与可判定性。 |

P0 包含数据破坏、核心流程失效。P1 包含错误事实或答案、答案泄露、实质歧义、关键阅读障碍。上述缺陷必须修复并通过独立复验。局部润色或轻微美术问题记为保留，有具体影响的均需说明处置。

## 执行与恢复

1. 先提交本文件和 PROGRESS.md。按第 1–28、29–56、57–84 天连续推进，每 7 天在本分支提交进度与对应修复。完成单次 28 天后交接到下一首日。
2. 验收先读取实际版本的图文与题目，按日记三格事实、四题 ID 和独立答案，记录缺陷原文、位置及预期。图像本地查看实际裁切，避免传输 Base64。
3. 修复阶段单独处理已记录的实质问题，保留问题原文和基线。修复连同生成产物独立提交以取得真实 SHA，再进行与修复步骤分离的复验，记录复验身份、所测版本、步骤、结果。缺少独立复验的缺陷保持待签收。
4. 浏览器回归按原方案至少 12 天，固定第 1、2、47、61、84 天并以语言与画面风险择取其余 7 天。Chromium/WebKit × 320/390 CSS px × 全拼音/无拼音共 96 场景，另对 4 个高风险场景补测 375/414/768 CSS px 与重点/按需拼音。验证翻格、正文滚动、点击汉字、朗读、提交、刷新续做、首次作答保护和 Q0 标注导出。隔离档案只创建合成记录。
5. 84 天联合内容和必要界面全部签收，所有实质缺陷完成独立复验后，统一运行现有阅读、插画、Q0 及定向保护回归。核对科目及 Q0、既有事件、草稿、备份、历史与朗读/拼音/答题行为，保留原资源和原公开入口。M2/W2 不在范围。
6. 合并后核对 Pages 部署对应的发布 SHA、入口及被引用资源公网字节，跑隔离浏览器重点流程。完成时生成 REPORT.md，引用候选与发布 SHA、CI、部署、线上证据和延期项目，并更新 Issue #45。阶段受阻时写入 PROGRESS.md，下一次从其精确断点继续。
